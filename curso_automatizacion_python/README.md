# Curso de Automatización de Procesos en Python

Curso práctico basado en proyectos para automatizar tareas repetitivas de archivos, web, documentos e interfaz gráfica.

## Estructura

```text
curso_automatizacion_python/
├── modulo_1_archivos/
├── modulo_2_web_scraping/
├── modulo_3_ofimatica/
├── modulo_4_interfaz_tareas/
├── datasets/
├── requirements.txt
└── README.md
```

## Requisitos

- Python 3.11 o superior.
- VS Code y extensión de Python.
- Entorno virtual recomendado.
- Ejecutar primero los modos de prueba antes de interactuar con archivos, sitios o aplicaciones reales.

## Ruta de aprendizaje

1. Automatizar archivos con `pathlib`, `os` y `shutil`.
2. Extraer datos respetando términos de uso y límites de frecuencia.
3. Generar documentos y reportes con datos estructurados.
4. Coordinar tareas programadas y automatización visible de interfaz.

Cada módulo contiene una guía, un archivo base para el estudiante y una solución docente.
